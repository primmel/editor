# The Primmel Studio demos

Worked examples of real models built with Primmel Studio.

## [r7-clinical-thermometer](r7-clinical-thermometer/)

OIML R 7 (1979) — Clinical thermometers (mercury-in-glass, with
maximum device): the complete tutorial model — subject, requirements
with clause URNs, conformance tests, the simulatable verification
workflow, and the doc map back onto the source document. The dual
demo with the [smart-r60
classroom](https://github.com/oimlsmart/smart-r60): r60 teaches the
methodology; R 7 proves you can apply it.
