## The demo script (the golden path, in show order)

1. **The corpus comes home** — open oiml-r60-lml through the package
   API (the full uses closure), canvas renders. Legacy showcase 5
   (BS6004) imports: the rename report (measurement→variable,
   subprocess→canvas), the 27 expressions execute, the TABLE variables
   derive from the BS6004 grid. **Plane: retention (done).**
2. **Mapping + inference** — the automap bridges an implementation to
   its reference (G1 seeds transitive suggestions); the mapping diff
   (G3) computes the coverage delta on a reference update; the 13485
   fixture shows edition-crossed maps (G15) with edition compare (G6).
3. **Adoption** — adopt a term/requirement from the reference into the
   implementation; the map creates itself (G5).
4. **THE DATA PLANE** — the workspace: registry rows in schema-driven
   forms, saved through the git-backed save API (one commit per save,
   the log IS the workspace history). Real package, real commits (G13).
5. **THE DIGITAL TWIN** — the tick pipeline: a clock drives a
   measurement stream (the BS6004 table lookup as the "sensor" —
   evaluateTableVariable over real corpus data), the model evaluates
   per tick, registers + log + edge-triggered alert surface (G14,
   editor-side for the demo — the smart monitor plane stays the
   other agent's lane; this is the reversible default).
6. **The check plane** — `primmel check` on the composed package,
   KNOWN allowances live, C157/REG-01 holding.
